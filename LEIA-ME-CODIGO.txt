GUIA DE LEITURA DO PORTFOLIO
============================

Este documento explica o HTML, o CSS e o JavaScript usados no site. Os
numeros indicados sao linhas dos arquivos atuais:

  index.html  - estrutura e conteudo da pagina
  style.css   - aparencia, cores, espacamentos e adaptacao a telas
  script.js   - interacoes e conteudo criado dinamicamente

Os numeros podem mudar se os arquivos forem editados. Linhas vazias servem
somente para organizar e separar visualmente o codigo. Em HTML, CSS e
JavaScript, chaves e tags de fechamento encerram blocos iniciados antes.


1. HTML: index.html (265 linhas)
===============================

       Declara o documento como HTML5 para o navegador.

       celulares.
6      <meta name="description" ...>
       Fornece uma descricao curta da pagina para mecanismos de busca.
7      <title>...</title>
       Define o titulo exibido na aba do navegador.
8-10   <link rel="preconnect"...> e fontes
       Antecipam conexoes ao Google Fonts e carregam DM Sans e Space
       Grotesk, usadas no desenho do texto.

       metadados de instalacao. Os arquivos apontados ficam em imagens/.

263     <script src="script.js"></script>

265     </body> / </html>
       Fecham o corpo e o documento.

NOTAS DE ATRIBUTOS HTML
-----------------------
class associa elementos a regras CSS. id identifica um elemento de forma
unica e serve a links, acessibilidade e consultas do JavaScript. href define
o destino de um link; src indica o arquivo de uma imagem ou script. alt
fornece texto alternativo para imagens. hidden esconde um elemento.
aria-* complementa a acessibilidade; data-* guarda dados usados pelo script.
article representa um item independente, section agrupa conteudo tematico,
nav e a navegacao, main e o conteudo principal, e footer e o rodape.

COMO LER AS REGRAS
------------------
Uma regra CSS tem um seletor entre chaves e declaracoes dentro dele. O
seletor escolhe elementos; cada declaracao e propriedade: valor. Por exemplo,
color: red altera a cor do texto. Ponto e virgula encerra uma declaracao,
chaves encerram uma regra e virgulas permitem agrupar seletores. Linhas
vazias e comentarios /* ... */ nao alteram o desenho.

  --accent e --dark-green. Elas centralizam cores que podem ser reutilizadas
  com var(--nome).

PROPRIEDADES CSS MAIS IMPORTANTES
---------------------------------
display: flex/grid escolhe o modelo de layout; align-items alinha no eixo
transversal; justify-content distribui no eixo principal; gap cria espaco.
width/height definem dimensoes; max-width/min-height limitam dimensoes.
padding e espaco interno; margin e espaco externo. color e cor do texto;
background e fundo; border desenha borda; border-radius arredonda cantos.
font-size, font-weight e line-height controlam texto. object-fit ajusta
imagens; position e top/right/bottom/left/inset posicionam elementos.
overflow controla conteudo que excede a caixa. transition suaviza mudancas;
transform move, escala ou gira; box-shadow cria sombra. @media adapta estilos
conforme largura da tela.

SINTAXE E CONCEITOS JAVASCRIPT
------------------------------
const declara uma referencia que nao sera reatribuida. () => {} e uma funcao
seta. document.querySelector busca o primeiro elemento CSS correspondente;
querySelectorAll busca todos. addEventListener registra uma acao, como click.
forEach percorre itens. classList altera classes. setAttribute altera
atributos HTML. template strings usam crases e ${...} para inserir valores.
Array.from cria arrays; length determina quantidade; ternario (condicao ? A
: B) escolhe entre valores. && significa "e"; || fornece alternativa.
return encerra uma funcao; event.target identifica origem do evento;
preventDefault cancela a acao padrao do navegador.

OBSERVACAO SOBRE NUMERACAO DO JAVASCRIPT
----------------------------------------
Os intervalos desta secao descrevem os blocos logicos. Para uma linha exata,
consulte o numero mostrado pelo editor no arquivo script.js. Se linhas forem
adicionadas ou removidas, a numeracao deste guia precisara ser atualizada.
